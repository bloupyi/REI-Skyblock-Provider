# REI Skyblock Provider 1.6.4

Fixes recipe and usage access when Skyblocker is installed. The provider now isolates Skyblocker's two REI plugins by default while keeping the rest of Skyblocker active.

## Compatibility

- Skyblocker remains optional. Its configuration files are not modified.
- `disableSkyblockerReiIntegration=true` prevents Skyblocker's REI categories, entries, comparators, screen hooks and transfer handlers from registering. Previously registered recipe generators become inactive.
- Set this provider option to `false` to use coexistence mode, then run `/reisbreload`. Changing modes triggers a full REI reload.
- Coexistence mode protects existing entries from Skyblocker's registry clear and ignores generated displays whose categories were removed by a reload.
- Existing recipes remain accessible when an item information display would otherwise suppress REI's wildcard fallback. Vanilla and other mods' visibility filters remain respected.
- Only identical provider-owned recipes are deduplicated; different methods, costs and stations remain available.

## Diagnostics

Enable `debugLogging` and use `/reisbdebug ITEM_ID` to compare indexed recipes and usages with REI's final results. Logs include SkyBlock IDs, categories, generators, comparator mismatches and repository loading state. `/reisbstatus` reports the isolation mode.

## Installation

Minecraft **26.2**, Java **25**, Fabric Loader **0.19.5**, Fabric API **0.161.0+26.2**, REI **26.2.820**, Architectury API **21.0.2**, and Cloth Config **26.2.155**.

Install **rei-skyblock-provider-1.6.4+mc26.2.jar** and replace the previous provider JAR. The `-sources.jar` and `-project.zip` files are for development.
